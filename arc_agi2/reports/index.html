How we build the missing generators
1. Read the explanation and transformation
2. Define valid latent objects and constraints
3. Construct fresh inputs and independent outputs
4. Compare with original examples and teacher solver
5. Probe new sizes, edge cases and alternative rules
Each missing task has a reference packet in the fork: canonical grids, labelled corrected teaching copy if applicable, saved explanation, transform code and provenance. A solver alone is not an input generator. Replaying examples or recolouring them does not count as fresh mechanism coverage.
All 1,120 public tasks are training-eligible, including the former 20 holdouts. Synthetic validation measures new-input generalization. Bulk generation is stopped until coverage is complete. The new constructive generators and two size extensions are tracked by sampled differential checks; they are research implementations with limited semantic coverage, not proofs that all possible variants are correct.
